# App Forge

## What you can do
Create and evolve dedicated interfaces for repeatable workflows.

## Example workflow
Start from a blueprint for field dispatch, research, or software delivery, then review the generated app.

## Before you start
Blueprint maturity varies. Generated code needs review and an approved execution environment; local generated-app builds are blocked in production.

## Review the outcome
Check results in your workspace before using them operationally. Available actions depend on your organization permissions and configured services.
