# Computer use and human takeover

## What you can do
Work through a browser interface when a direct integration is insufficient.

## Example workflow
Let an agent carry out a supervised browser task, take over when needed, and review a captured procedure for reuse.

## Before you start
An administrator-enabled computer-use runtime, an organization desktop, a provider key, and authorized access to the target service.

## Review the outcome
Check results in your workspace before using them operationally. Available actions depend on your organization permissions and configured services.
