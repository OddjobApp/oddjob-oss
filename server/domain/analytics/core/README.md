
# Analytics Core Services

This module contains the core services responsible for business intelligence, cost tracking, and performance analysis across the Oddjob platform.

## Core Responsibilities

The services in this module provide the data and insights for various analytics dashboards and reporting features.

### Key Services

- **`analytics.service.ts`**: A general-purpose service for tracking and querying key platform events and metrics.

- **`cost-calculator.service.ts` & `cost-attribution.service.ts`**: These services work together to track the cost of every AI call and attribute that cost to a specific user, team, or project. This is critical for managing budgets and understanding the financial performance of the platform.

- **`roi.service.ts`**: The Return on Investment service. It provides higher-level analysis to help determine the business value generated by various automations and AI agents.

- **`rca.service.ts`**: The Root Cause Analysis service. This service is used to analyze chains of events to help identify the underlying cause of failures or unexpected outcomes.

- **`reporting.service.ts`**: A service for generating and exporting structured reports on platform usage, costs, and other key metrics.
