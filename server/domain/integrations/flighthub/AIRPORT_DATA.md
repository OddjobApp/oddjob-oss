Airport directory snapshot: October 8, 2026.

Source: https://ourairports.com/data/ and
https://davidmegginson.github.io/ourairports-data/airports.csv

OurAirports releases its data to the public domain. This compact snapshot
retains active airport records with IATA codes, names, municipalities, country,
airport type, scheduled-service status and search keywords. It is reference
data, not live flight or fare data. Runtime lookups are local and require no
AI inference, credentials or recurring network calls.

City catchment aliases in airport-directory.ts distinguish metropolitan areas
from individual municipalities. Ambiguous cities return named airport options;
they do not silently choose an airport. Update the snapshot from the source
CSV when refreshing reference data.
