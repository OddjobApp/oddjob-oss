# Archived status reports

Point-in-time reports, phase write-ups, and superseded proposals that used to
sit in the repository root. They are kept because they record why decisions
were made, not because they describe the system as it is today.

**Nothing in this directory is authoritative.** For current state see:

- `README.md` and `DESIGN.md` at the repository root
- `docs/FEATURES.md` — what exists
- `docs/FEATURE_MATURITY_ROADMAP.md` and `docs/CAPABILITY_MATURITY_RUBRIC.md` — how complete each area is
- `ROADMAP_2026_Q3.md`, `ROADMAP_2026_Q4_H1_2027.md` — what is planned

They were moved here because 69 markdown files in the repository root — most of
them titled `*_COMPLETE.md` — is the first thing a reviewer sees, and it reads
as noise regardless of the quality of the work underneath.

Cross-references between files in this directory are bare filenames and still
resolve, because the whole set moved together.
