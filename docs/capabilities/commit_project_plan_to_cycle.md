# 🛠️ Save Project Plan as Cycle (pending approval)

> **Capability ID:** `commit_project_plan_to_cycle`  
> **Capability Version:** `1.0.0`  
> **Manifest Schema:** `v1`  
> **Category:** System Utilities  
> **Owner:** platform  
> **Risk Profile:** Low  
> **Execution Environment:** Host

---

## Overview

Saves a Project Studio wave plan as an Operational Cycle that is PENDING APPROVAL. Nothing runs until someone approves the cycle. Waves carry dependencies (predecessor wave ids), acceptance criteria, tasks, studio targets and assignees; human-assigned waves become approval milestones, not AI missions.
