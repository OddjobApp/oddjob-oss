Lists available application architectures (blueprints) that can be used to scaffold a new app, each with its maturity (stable, beta or experimental). Prefer a stable or beta blueprint, and tell the user when the one you pick is experimental. Blueprints include 'analytics-dashboard', 'chat-assistant', 'crud-app', etc.
