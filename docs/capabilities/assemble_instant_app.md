## Overview

Compose MULTIPLE pre-built UI blocks into a single instant-app surface rendered live in the chat (no build/deploy). Use this when a task needs several blocks together — e.g. a dashboard = a metric grid + a table + a status timeline. Pick blocks from list_instant_app_components and pass props matching each block's interface. Prefer this over multiple render_instant_app calls when the blocks belong together as one surface.
