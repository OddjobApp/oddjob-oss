## Overview

Render an INTERACTIVE form in the assistant chat to collect input, build a live CALCULATOR, or render a LIVE DATA APP (e.g. weather forecast, currency converter, market metrics, sensor feeds). Use this whenever the user needs an on-the-fly interactive tool — forms, data entry, calculators, and live API apps — NEVER describe a form or app in prose. It renders immediately as an interactive component. Supports 'number'/'location' inputs, 'query' fields that fetch external APIs live via Oddjob's governed HTTP connector, and 'computed' fields whose `formula` is evaluated LIVE as the user types (field chaining), so real calculators and live weather/finance tools work: e.g. a weather app = { type:'query', url:'https://api.open-meteo.com/v1/forecast', params:{ latitude:'{{latitude}}', longitude:'{{longitude}}', current_weather:'true' }, jsonPath:'current_weather.temperature', unit:'°C' }. Formula language: + - * / %, comparisons (== != > < >= <=), logic (&& || !), and functions round/floor/ceil/abs/min/max/sum/avg/clamp/pow/sqrt, upper/lower/title/trim/concat/left/right/contains/replace, if(cond,a,b)/coalesce(...). FINANCIAL FUNCTIONS: pv(rate,nper,pmt,fv,type), fv(rate,nper,pmt,pv,type), pmt(rate,nper,pv,fv,type), rate(nper,pmt,pv,fv,type,guess), nper(rate,pmt,pv,fv,type). Reference other fields by their key.
