## Overview

Returns an assistant_app payload to mount an adaptive Builder Pod (ScaffoldPackPod, PipelineBuilderPod, AgenticHRPod, HILGovernancePod, MissionBriefPod, DatasetSchemaPod, DocumentDeckPod, OntologyLinkTypePod, ProjectPlanningPod, ProjectStudioPod, DecisionMatrixPod, AgentUpskillingPod, ToolScaffoldPod) inline in chat. 'podComponent' is required. 'stageId' is optional.
