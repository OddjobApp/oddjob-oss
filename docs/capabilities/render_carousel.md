## Overview

Render a swipeable card carousel in the assistant chat to present 2+ items the user browses one or a few at a time. Use this for products, document versions, generated options, search results, or image cards — anywhere a list is too flat and a table is too rigid. Each card supports an image, badge, subtitle, tags, key facts, and a CTA link. For apps/workspaces use render_app_catalog instead; for attribute-by-attribute comparison use render_comparison; for 4+ rows of tabular data use render_table.
