# 🧩 Draft a Media Studio Story

> **Capability ID:** `propose_media_story`  
> **Capability Version:** `1.0.0`  
> **Manifest Schema:** `v1`  
> **Category:** Video Content  
> **Owner:** platform  
> **Risk Profile:** Low  
> **Execution Environment:** Host

---

## Overview

Drafts scenes for a Media Studio production from what the author described — each with its direction, beats, shots and dialogue — and returns them as a card for the author to apply. Writes nothing.
